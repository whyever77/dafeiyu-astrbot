遗忘曲线、模拟巩固和线索检索仍在本地计算，不改变她在 QQ 中的记忆行为。

本地[她的小小房间 v0.2](ROOM_V02.md)：从左侧进入 `/room`，默认总览，可走近书桌、书架、窗边和休息角；大肥鱼角色会待机、走动、写字、阅读、望窗和睡觉，窗景跟随上海时间。支持显式只读活动库来源，不从记忆猜测当前状态。纯演示有清晰的虚构标识；真实记忆模式未接活动源时显示未知。文件升级后需重启本机观测服务。

## 运行

Windows 桌面入口：**「记忆星海」鲸鱼图标**。双击后打开真实只读 LivingMemory，并带 `--life-ssh`
同时只读连接活动账本；已有真实服务直接复用（不重复启动、不刷新），未启动时用 `pythonw.exe`
隐藏启动，等待就绪后打开默认浏览器。连续点击串行检查启动状态，端口被其他服务或演示模式占用时提示，
不覆盖、不结束现有进程，也不回退到虚构数据。

在当前仓库中安装/更新桌面快捷方式（会保存当前仓库绝对路径，移动仓库后需重新运行）：

```powershell
& .\deploy\memory_observatory\install_shortcut.ps1 -Pythonw 'C:\Users\ACER\miniconda3\pythonw.exe'
```

快捷方式参数为 `-B -m deploy.memory_observatory.launcher --life-ssh`；旧快捷方式重跑本脚本即可原地升级。
图标原图与多尺寸 ICO 位于 `assets/memory-whale.png`、`static/memory-whale.ico`。
删除桌面 `.lnk` 即可移除快捷方式；没有注册登录启动项或后台定时任务。
关闭浏览器不会关闭本地观测服务。新服务提供不含记忆内容的 `/api/health` 供启动器检查；
兼容已运行的旧 v0.2 时，仅在内存里核对页面标识与快照的真实来源字段，不导出或记录正文。

2026-10-29 Windows 验证：`python -B -m unittest discover -s tests -p 'test_memory_*.py' -v`
共 58 项通过（0 skip），包含启动器新增 10 项。实际调用桌面 `.lnk` 返回退出码 0，
调用前后为同一个本地服务进程，来源检查均为真实 LivingMemory。
图标使用内置图像生成工具，最终提示词与文件说明见 [ICON.md](assets/ICON.md)。

在仓库根目录运行（Python 3.10+，仅标准库，无需安装依赖）：

```powershell
python -B -m deploy.memory_observatory.server --port 8767 --livingmemory-ssh
```

打开 <http://127.0.0.1:8767>。使用已有运维配置：`DAFEIYU_SSH_HOST` 或 `~/.dafeiyu-admin/host`，
以及 `~/.ssh/ecs_dafeiyu`。SSH 必须能以非交互方式连接，目标主机密钥必须已经在 known_hosts 中受信任；
不会关闭主机校验。主机、密钥和数据库路径不能通过页面指定。

启动和「同步真实记忆」会读取一次；勾选「每 60 秒自动同步」后，页面可见时每 60 秒只读重新读取一次，浏览器标签隐藏时暂停。自动同步可随时关闭，不重置当前筛选或实验。
首次读取失败就退出；后续同步失败会保留上次快照并显示「旧快照」。每次最多一个同步请求。
真实模式隐藏并拒绝导入/返回演示，避免把合成数据混入真实来源。

也可以在另一个端口运行虚构演示或手动导入模式：

```powershell
python -B -m deploy.memory_observatory.server --port 8766
```

打开 <http://127.0.0.1:8766>。在启动它的终端按 `Ctrl+C` 停止。
端口占用时换一个 `--port`。只绑定 `127.0.0.1`，不支持把绑定地址改成公网或局域网地址。

浏览器使用 ES modules、Canvas 2D、原生 dialog 和本机字体，无 CDN、远程字体或模型请求。
未指定真实连接参数时，默认 35 条**虚构**记忆，分为私聊演示 32 条、群聊隔离演示 3 条。不是从主人的聊天中提取。

## 可以体验什么

2026-10-30 的星域 v0.3 把矩形分类格改为深蓝星域：每个类别有固定的方向、深度和大小，
远近由相机透视计算；拖动缓慢环视，滚轮推拉，点击悬浮星域名平滑靠近，再点一次或 `⌾` 返回全景。
选中记忆后再次点击同一节点取消选中；2D 正交阅读入口保留，60 秒同步不重置相机。

2026-10-30 的 [房间与页面 v0.2](ROOM_V02.md) 已接入主人确认的大肥鱼角色和六组动作。
进入 `/room` 默认总览，点击角落会平滑特写并开始对应活动；窗外随上海时间改变。
星海按记忆的形状/类型分区，选中关联更清晰，遗忘模拟连续过渡；沿用 60 秒只读同步。
活动账本可追加 `--life-ssh` 显式连接，使用独立的「同步近况」，动画不作为真实执行证据。

1. 在星图中拖动、缩放或切换 2D 阅读；点击节点或下方记忆卡片查看片段、意义、来源和关联。
2. 输入「雨声」，观察直接匹配和一跳关联的召回路径。清除线索后退出召回视图。
3. 把时间轴拖到半年后。细节可及度下降，意义衰减更慢；原始文字和来源仍可以审阅。
4. 对单条记忆切换「模拟巩固」「模拟保留」，对照曲线；重置实验恢复快照参数。
5. 打开「共同经历」按时间浏览；「遗忘实验室」解释参数和整个作用域的变化。
6. 切换到群聊演示，私聊片段不会进入其列表、检索或关联扩散。
7. 真实模式查看来源面板和原库观测值；演示模式可导入下方协议的 JSON 快照，非法文件会整体拒绝。

大小表示重要度，亮度表示模拟可及度，固定圆环表示保留。虚线只表示共同主题推导的关联；
实线表示快照来源标注的关联，并不自动等于经过验证的事实。节点距离是布局结果，不是语义距离。
背景细小星尘只是装饰，不计入记忆数量。动画默认尊重系统的减少动态效果设置，也可手动暂停。

## 遗忘与召回的准确含义

| 维度 | 实现 | 不代表什么 |
|---|---|---|
| 细节可及度 | `2 ** (-age_days / stability_days)` | 人脑实测曲线、来源真实性 |
| 意义可及度 | `2 ** (-age_days / (3 * stability_days))` | 自动生成的新结论 |
| 默认稳定度 | 经历 30 天、偏好 120 天、知识 90 天、方法 180 天；未提供时标记假设值 | 已拟合这位用户的参数 |
| 模拟巩固 | 当前视图稳定度乘以 1.6，可逆、幂等；不改变原召回时间 | 一次真实聊天事件、独立证据增加 |
| 模拟保留 | 两条可及度曲线保持为 1，可逆 | 修改人格、删除策略或真实记忆状态 |
| 来源可信度 | 只显示导入字段；缺失为「未评估」 | 随着浏览次数自动提高 |
| 召回 | 中文二元词片段/英文词匹配，按意义可及度与重要度排序，最多 5 个直接匹配 + 3 个一跳邻居 | 向量召回或模型内部思维 |

时间从快照的 `as_of` 向未来偏移；遗忘年龄从 `last_recalled_at`（未提供则 `created_at`）计算。
所有投影都是纯函数。浏览、搜索、拖动、反复调用 API 不增加访问计数，也不自动巩固。
重复模型复述没有被当作新的证据。当前的「淡去」不是物理删除，也不隐藏观测台内供审阅的原文。

## 导入协议

演示模式的「导入记忆快照」可下载完整格式。真实模式不开放此入口。最小示例：

```json
{
  "schema": "memory-observatory/v1",
  "label": "我的记忆快照",
  "as_of": "2026-10-28T12:00:00+08:00",
  "memories": [
    {
      "id": "episode-001",
      "scope": "private:owner",
      "title": "一起听雨",
      "text": "需要由你从真实来源提供的原始片段。",
      "gist": "需要由来源提供的摘要。",
      "kind": "episode",
      "topics": ["雨声", "音乐"],
      "created_at": "2026-10-25T20:00:00+08:00",
      "last_recalled_at": "2026-10-26T20:00:00+08:00",
      "importance": 0.8,
      "confidence": null,
      "half_life_days": 30,
      "pinned": false,
      "source": "来源标识或聊天事件编号；请勿包含凭据"
    }
  ],
  "edges": []
}
```

- 必须提供 `schema / as_of / memories`；每条记录必须有 `id / scope / title / text / created_at`。
- 时间必须带时区，创建与最后召回时间不得晚于快照；召回不得早于创建。
- `kind` 支持 `episode / preference / knowledge / method / document / plan / relation / unclassified`。
  `importance` 和非空 `confidence` 范围 0–1。`plan` 是计划，不代表已经发生。
- `half_life_days` 范围 1–3650。省略时采用类型默认值并标记假设；再次导入可保留布尔 `stability_assumed`。
- `gist` 省略时采用标题；不会调用模型补写。`pinned` 默认 false。来源缺失会明确注明。
- 最多 500 条、4 MB、每条正文 4,000 字符、8 个主题；未知元数据被丢弃，不透传任意 metadata。
- `edges` 最多 4,000 条，格式 `{"source":"id-a","target":"id-b","label":"关联依据","weight":0.7,"inferred":false}`。
  必须指向同一作用域的不同有效记录；共同主题会补充有限数量的推导关联。重复导入不会继续增加关联。
- 导入不是合并；它在整个校验成功后替换当前服务内存中的数据。刷新浏览器保留本地进程内的导入，清空实验状态；
  点击返回演示或重启服务清空导入。没有数据库、磁盘保存、自动导出或文件路径读取接口。
- 此进程内的所有本地浏览器标签页共享同一个导入快照；作用域选择不是用户鉴权机制。不要反向代理公开此服务。

## 与现有 LivingMemory 的边界

适配依据是实际安装的 `2.7.0-beta.2` 源码与 SQLite 表结构，不接受任意版本原始导出。
版本不同或列结构不匹配就拒绝读取，需要重新审计适配器。SSH 通过标准输入运行固定的标准库读取器，
不在云端保存脚本、不导入插件代码、不读取 conversations.db、不调用测试召回或包含原始消息的导出接口。

- 使用 SQLite `mode=ro`、`query_only` 和 SQL authorizer，只读事务可见已经提交的 WAL 数据。
- 读取活跃文档及其有效原子；排除 expired/forgotten/到期原子。文档必须有明确的 session_id 与 persona_id 字段；
  原子必须与已载入父文档归属一致。空人格、显式 null 人格和命名人格分别隔离，缺键记录隔离排除。
- 作用域以会话与人格的组合生成不透明标识。页面只显示当前作用域的内容、检索和关联；本机页面不是多用户授权系统。
- 显示原库 TTL、过期时间、访问/强化次数；TTL 不充当模拟半衰期，缺失可信度保持「未评估」。
  缺失访问时间会标记并从创建时间模拟；默认稳定度仍是假设值。
- 星图中的实线表示真实文档到原子的来源归属；详情最多显示每篇文档的 5 条活跃实体关系。
  这不是全量实体图谱展示，也不是事实核验；主题虚线仍为本地推导。
- 整体上限 500 条，按文档优先、各表 ID 倒序选择；正文最多 4,000 字符，摘要 500 字符。
  面板报告过滤、归属排除、无效及超量记录；截断正文单独标记。不会读取原始聊天消息或透传任意 metadata。
- 只读快照保存在本地服务内存；不自动写文件，不记录正文、检索词、SSH 错误体或凭据。
  服务只绑定回环地址，不应公开反向代理。关闭本地进程即可停止观测，无云端改动需要回滚。

真实召回事件流、向量检索、写回、删除与新的遗忘策略均未接入。本次不改变原引擎生命周期调度；
后续策略实验需要独立的离线评估、备份和回滚设计，避免双重衰减与巩固。
