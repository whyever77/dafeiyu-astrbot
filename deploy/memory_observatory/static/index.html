THE ART OF LETTING GO

遗忘，也有温柔的秩序。

移动下方时间轴，观察整个星海。选中一段记忆，可以单独模拟巩固与保留。

01 / 时间

细节先淡，意义后留

同一片段有两条曲线。意义的模拟半衰期是细节的 3 倍。

02 / 巩固

有意义地再次想起

一次模拟巩固把稳定度乘以 1.6。浏览与模型复述不会自动强化记忆。

03 / 边界

熟悉，不等于真实

可及度会变化，可信度保持独立。关联线也不代表因果或事实证明。

这些曲线是可调的工程模型，不是对人脑神经元的测量。当前实验不修改任何真实记忆。

ABOUT THIS OCEAN

让记忆可见，也让边界清楚。

这是一座本地记忆观测台。光点代表有来源的记忆片段，连线代表来源标注或共同主题。它不展示模型的真实神经元。

大小
记录中的重要程度
亮度
工程模型估计的细节可及度
虚线
共同主题推导的联想，不是事实
光环
当前选中或被本次检索唤起
固定圆环
原记录保留或实验中的模拟保留

当前未连接 LivingMemory。所有实验只作用于内存快照，浏览不增加访问计数，不巩固、不删除原记忆。页面刷新会清空实验；服务重启会清空导入。

半衰期是演示参数，可信度由来源提供，不随“想起次数”增长。此版本的召回是可解释的关键词与关联检索，未使用向量模型。
BRING YOUR OWN MEMORIES

把一份记忆，带进星海。

选择本机 JSON 快照，数据只进入此本地进程的内存。导入会替换当前观测数据，保留原文件。

格式：memory-observatory/v1
最多 500 条 / 4 MB，必须包含明确作用域。
