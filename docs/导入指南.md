# 导入指南 · 人格 / 课程记忆 / 音色

> 前提：已按《部署指南》把 AstrBot + NapCat + QQ 小号跑通（能收发纯文字）。
> 三节内容互相独立，按需取用。
>
> 📁 文中「AstrBot 数据目录」= 你部署里的数据文件夹：
> Launcher 安装版在 `…/instances/<实例id>/core/data/`；手动部署版在 AstrBot 根目录的 `data/`。

---

## 一、导入人格（约 5 分钟）

**1. 直接复制 `persona/大肥鱼-人格.md` 的正文：**

从 `---` 之后的"你是「大肥鱼」…"第一句开始，到"这些例子只示范语气…合时宜的话。"最后一句，**整段粘贴**即可。

> v2 起是单块提示词，不再需要拼接收尾块 / 群聊守则 / 朋友来访；标题和引用说明不用粘贴。

**2. 在 AstrBot 里新建人格**

1. 打开 AstrBot 面板（Launcher 版在托盘菜单里点开，或浏览器访问 `http://localhost:6185`）
2. 进「配置」→「人格」→ 新建
3. 名称填 `大肥鱼`，系统提示词粘贴拼好的正文，保存

**3. 启用她**

- 全平台默认：在配置里把默认人格设为「大肥鱼」
- 单会话：在对话里对目标会话切换人格

**4. （可选）开场白**：人格编辑里如果有「开始对话」栏目，可以加一条她的开场白
（比如"唔？你回来啦！(・∀・)"）；没有这栏就跳过，不影响开聊。

**5. 验证**：发一句"在吗"。回话应该是"嘴硬 + 语气词"的调子，不是客服腔；
若不是，先检查这个会话是不是没有启用她。

## 二、导入课程记忆（约 10 分钟）

「课程记忆」= 写进长期记忆的**自省小课**（用她自己的口吻："我琢磨明白了…"）。
被召回时她会当成"自己本来就懂的道理"，比系统提示词里的硬规矩自然得多。
课程文本见 `persona/课程记忆-模板.md`。

### 路子 A（推荐）：当面教

1. 把课程**分几次**发给她（一次一条，别刷屏）；
2. 每条发完让她**用自己的话接一句**（或问"记住啦？"）；
3. 原理：livingmemory 会把**她的那段回应**存成她自己的记忆——是"她亲口说过的话"，
   不是外部灌进去的规矩。

### 路子 B（进阶）：直接写记忆库

> ⚠️ 动手前先备份：把 `livingmemory.db` 复制一份。

1. 记忆库位置：`AstrBot数据目录/plugin_data/astrbot_plugin_livingmemory/livingmemory.db`（SQLite 文件）
2. 用任意 SQLite 工具（如 DB Browser for SQLite）打开，往 `documents` 表插入：

```sql
INSERT INTO documents (doc_id, text, metadata, created_at, updated_at)
VALUES (
  lower(hex(randomblob(16))),
  '<课程正文>',
  '{"session_id":"qq:FriendMessage:<你的QQ号>","persona_id":"<你的人格id>","importance":0.8,"create_time":' || strftime('%s','now') || '}',
  datetime('now'), datetime('now')
);
```

3. 保存后重启 AstrBot。

注：直接写库会绕过插件的自动索引流程，召回效果随插件版本而异——稳一点优先走路子 A。

**验证**：过一阵聊到相关话题，看她是否自然带出来。别用"背一遍给我听"考她——那会把课变成背书。

## 三、导入音色（主要花在录素材和等复刻）

**0. 先看懂素材**：`assets/voice-demo/` 里的样本是**成品演示**（合成输出），
不能拿去当复刻素材——复刻要的是"人声原汤"。

**1. 录素材**：10~20 秒干净人声（单条连续说话；无 BGM、无混响；采样率 ≥24kHz；
安静房间里离手机 20cm 左右就达标）。具体要求以百炼控制台页面为准。

**2. 做复刻（百炼控制台）**：
「体验中心 → 语音模型 → 音色复刻」→ 上传素材 → 等复刻完成 → 复制 **voice_id**
（形如 `qwen-audio-3.1-tts-flash-bailian-<一串id>`）。

**3. 接到 AstrBot**：「配置 → 提供商」新建，类型选 **DashScope 语音（dashscope_tts）**，填：

| 键 | 值 |
|---|---|
| `api_key` | 你的百炼 API Key |
| `model` | `qwen-audio-3.1-tts-flash` |
| `dashscope_tts_voice` | 上一步的 voice_id |

保存后，在 TTS 设置里把它设为默认提供商（`provider_tts_settings.provider_id`）。

**4. ⚠️ 必打核心源码补丁**：原生 AstrBot 接 `qwen-audio-*` 会直接合成失败（url error），
且语速/音高配置不生效。完整补丁随 `deploy/patches/` 提供（TTS 两处见《踩坑合集》**第 15 条**，
分泡/整段语音见第 23 条）。**升级 AstrBot 后会覆盖补丁，需按新版源码重打。**

> 听写/视频理解的凭证与 TTS **解耦**：在插件 `config.json` 填
> `asr_api_key`（或容器环境变量 `DASHSCOPE_API_KEY`），换音源、改 TTS provider id
> 都不会影响 `qwen3-asr-flash` / `qwen3-vl-plus`。留空时才回退到旧 `dashscope_tts`。

**5. 调语音行为**（TTS 设置 / `provider_tts_settings`，WebUI 里能直接改）：

- `enable`：开
- `provider_id`：选你的 dashscope_tts
- `dual_output`：true = 文字 + 语音双发；false = 只发语音条
- `trigger_probability`：每条回复发语音的概率（0.08 左右比较自然，太高变复读怪）

**6. 调音（可选，M3 配方）**：补丁打完后，在 `cmd_config.json` 对应 provider 条目里加：

```json
"dashscope_instruction": "",
"dashscope_speech_rate": 1.04,
"dashscope_pitch_rate": 1.0
```

即"零指令 + 语速 1.04 + 音高 1.0"。**为什么指令留空**：给复刻音色加"撒娇/活泼"这类
指令，会把素材源的口音一起放大——这是试了 8 个变体后的血泪结论（见踩坑 #10）。

**7. 验证**：私聊说两句，她应按概率发来语音条；语音里不该念出"[旺柴]"这类表情标记
（念了 = 还缺第三个补丁，见踩坑 #14）。
