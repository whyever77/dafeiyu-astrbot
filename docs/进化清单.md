# 大肥鱼自主生活进化清单

按现有代码整理，更新于2026-11-02。拟人化体现在持续的选择、作息、偏好与真实经历；界面表演与实际活动分别呈现。每一步沿用现有调度、主人权限、审批和预算，不靠新增定时消息制造主动性。

| 阶段 | 做什么 | 当前证据与状态 |
| --- | --- | --- |
| 1. 自己选下一件事 | 未完成目标、自身兴趣、研究/写作/探索/休息的选择与理由 | `planner.py`；[生活决策](../deploy/bili_activity/LIFE_DECISION_V01.md)，已有部署记录 |
| 2. 合适的时候联系 | 联系额度、间隔、主人聊天后留白、未回应限制 | `contact.py`；[联系协调](../deploy/bili_activity/CONTACT_V01.md)，真实 QQ 联动仍待验收 |
| 3. 有可看见的小天地 | 角色、四个活动角落、活动账本和 LivingMemory 只读展示 | [房间](../deploy/memory_observatory/ROOM_V02.md)，睡姿与望窗八帧已接回；表演不证明活动发生 |
| 4. 形成生活节律 | 上海作息、睡前整理、依据实际活动时长留白、说明为什么休息 | [生活节律 v0.1](../deploy/bili_activity/LIFE_RHYTHM_V01.md)本地实现、离线验证，默认关闭；未部署或开启生产配置 |
| 5. 记忆巩固与渐忘 | 普通经历先淡化细节再淡出默认回忆；保护明确偏好与任务证据；不同实际内容支持的兴趣形成快照 | [经历记忆 v0.1](../deploy/bili_activity/MEMORY_POLICY_V01.md)本地实现、默认关闭，复用 LivingMemory 写入队列；485项离线回归通过，真实写入/长期效果未验证。星海曲线仍为模拟 |
| 6. 更连贯的自我表达 | 根据有来源的近期/此前兴趣、目标进展和已知中断说明近况 | [近况回顾 v0.1](../deploy/bili_activity/SELF_EXPRESSION_V01.md)本地实现、默认关闭，518项离线回归通过。沿用现有人格与情绪上下文，不生成情绪分数；真实表达效果未验证 |
| 7. 更丰富的自主项目 | 跨日主题、作品集、完成后的回看和新的问题 | [跨日项目 v0.1](../deploy/bili_activity/PROJECTS_V01.md)本地实现、默认关闭，551项离线回归通过；沿用目标/作品、调度与预算，先有工具及状态入口。真实长期效果、网页作品集待验证/接入 |

生活节律首版只改变下一轮生活选择与最长活动时长：夜间休息，临睡前仅整理已有作品，近期活动达到阈值时等待。原有公开写操作、QQ 联系、前台请求、DND、审批、未知结果不重试和预算继续独立约束。节律记录不写入长期记忆，不生成睡梦、吃饭或身体感受。

项目阶段启用后，睡前也可回看已有作品，仍不开展新研究。下一步先在隔离会话、低额度下验收跨日延续和真实表达，再把只读项目/作品集接到房间书架；本地离线通过不代表已经部署或长期有效。
